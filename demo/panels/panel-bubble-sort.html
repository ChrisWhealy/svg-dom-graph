Bubble sort

Bubble sort is the simplest way to sort by comparing. A pass walks along the array, comparing each element with the one next to it, and swaps the two if they are the wrong way round. The largest element left is carried along by the swaps until it reaches the end, like a rising bubble, so after each pass one more element is in its final place. The sort repeats until a whole pass makes no swap, which means every pair of neighbours is in order.
