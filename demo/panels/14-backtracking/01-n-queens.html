The N-Queens puzzle

Place N queens onto an N × N chessboard such that no two attack each other.

This page shows the whole search that finds every answer, one event at a time. The search is depth first. It works down the rows, and in each row tries the columns from left to right. It never skips a branch because the board is symmetrical, so what you see is the complete, honest search.

Each square the search looks at is one Try, which ends in one of two ways:

  • Reject. A queen above already attacks the square, so the search moves on to the next column.
  • Place. Nothing attacks it, so a queen goes there and the search starts on the next row. When a row has no free square left, the search goes back with a Remove that takes the last queen off, and tries the next column in the row above.

A board that has a queen in every row is a Solution. The search then goes on looking for more, and ends with Exhausted once every branch has been tried. A board of 8 has 92 solutions, and finding them takes 33,589 events.

Using the page

The selectors, the buttons and the range are in the scene, above the board.

  • Next and Previous move one event. Restart goes back to the empty board. A button that has nowhere to go is dimmed but can still be pressed, and then says so.
  • Play steps through the search at the speed you choose, and stops at the end. Pressing any other button, or moving the range, stops it. While it plays, only a solution and the end are announced to a screen reader.
  • The range goes straight to any step. Drag it, or use the arrow keys for exactly one step at a time. At 9 by 9 there are 153,502 steps, so dragging is coarse.
  • Previous solution and Next solution jump between the complete boards, never to the one you are already on.
  • Tab to the board, which is a single stop, then use the arrow keys to move between squares. Home and End go to the ends of the row, and with Control to the corners. The board only shows the search, so no key or click changes it.
  • Rows and columns are counted from 1 on the page. In the code and the tests they are counted from 0, so the two solutions of the 4 by 4 board are [1, 3, 0, 2] and [2, 0, 3, 1] there, and [2, 4, 1, 3] and [3, 1, 4, 2] here.

Why a board of 10 is missing

The search of a board of 10 has 732,563 events, which is more than this page keeps. Its 724 solutions are counted in the tests instead, without keeping the search.
