Binary operators

An operator node names the operation that produced its own single value — one of the six Boolean operators AND/OR/XOR/NAND/NOR/XNOR — without this crate ever computing that value itself. Each result shown here is computed by the demo, in plain Rust, exactly the way a real caller would; see DataNodeContent.

A binary operator node has two incoming edges, drawn automatically when the node is created, so the rendered graph can never drift from the operand relationship the node claims to represent.

See the Chained operators panel for an operator node's own result feeding a further operator node, rather than every row here standing alone.
