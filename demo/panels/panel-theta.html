Nested Scenes: SHA3's Theta function

A container node looks like any other node, but it owns one or more nested Scenes of its own — Scene::enter and Scene::exit navigate into and out of it, hiding and showing each <svg> root as they go. This lets a diagram stay small at the top level while a step that is genuinely complex still gets its own full-size view, one level down, without cluttering the parent.

The Theta function used within the SHA3 algorithm is a small, real example of exactly that shape. Internally, this function contains three subfunctions:

  1. ThetaC,
  2. ThetaD, and
  3. a final XOR loop that folds the ThetaD result back into the state array

Each inner function contains more functionality than can be displayed by a box on the parent diagram.

ThetaC below is a genuine container node: its own nested Scene is the exact same operator chain the Cell selection demo already draws — the same function, called again here, grafted under this diagram's own A node instead of drawn standalone. Click ThetaC to drill into it; a rounded, bordered frame marks it as a nested view, and the × in its corner closes it. ThetaD and the XOR loop are still plain placeholder boxes: there is no nested Scene behind them yet. This demo is deliberately incomplete — a start, not the finished function.
