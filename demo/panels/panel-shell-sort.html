Shell sort

Shell sort is insertion sort done at several distances. Sorting by swapping neighbours is slow because an element that is far from its place must be swapped past every element between. Shell sort first puts the elements a long way apart in order, so that an element can cross many places in one swap, and then does the same for a smaller distance. Each distance is a gap. The gaps here are the ones Shell first suggested: half the length, then half of that, and so on down to 1. For ten elements they are 5, 2 and 1.

For a gap of 5, the elements 5 places apart are treated as a short list of their own: places 0 and 5, places 1 and 6, and so on. Each element, from the one at place 5 on, is compared with the one a gap before it and swapped if they are the wrong way round, and is then compared with the one a gap before that, until it is in order with its list. Then the gap becomes 2, and then 1. A gap of 1 is a plain insertion sort, but by then the array is nearly in order, so it has little to do.
