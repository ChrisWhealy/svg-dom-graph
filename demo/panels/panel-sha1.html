SHA1

SHA-1 hashes a message in 64-byte blocks. This demo hashes one short message, so it needs only one block. Every value on screen is a real result of that one calculation, worked out in plain Rust.

The message block

The message is padded out to one 64-byte block, seen as 16 big-endian 32-bit words. The byte straight after the last message byte is the terminator, 0x80. The last 64 bits hold the message's length in bits, big-endian. This message is short, so only the last word, w15, is used.

The message schedule

The block is copied into the first 16 words of an 80-word schedule. Each of the other 64 is the XOR of four earlier words, rotated left by one bit: ms[n] = ROTL(ms[n-3] XOR ms[n-8] XOR ms[n-14] XOR ms[n-16], 1). While a word is being built, it is marked, and the four words it reads are marked as secondary.

Compression

Five working variables, a to e, start as the initial hash value. These five words, H0 to H4, are not worked out from the message. The standard fixes them: the first four are the bytes 01 23 45 67 89 ab cd ef fe dc ba 98 76 54 32 10 read as little-endian words, and the fifth is c3d2e1f0.

Each of the 80 rounds uses one schedule word, W[i], which is the word marked in the schedule, and one of four round constants K: one for each section of 20 rounds. The same sections choose the round function f.

temp = ROTL(a, 5) + f(b, c, d) + e + K + W[i], where f is (b AND c) XOR (NOT(b) AND d) for rounds 0 to 19, b XOR c XOR d for rounds 20 to 39 and 60 to 79, and (b AND c) XOR (b AND d) XOR (c AND d) for rounds 40 to 59.

The next working variables are e=d, d=c, c=ROTL(b, 30), b=a, a=temp.

The digest

After 80 rounds, each working variable is added to the initial hash word it started as. The digest is those 5 words, joined. Without that last addition, the result would not be a hash of the block. The last step writes the digest out as the usual 40-digit hexadecimal hash value.
