SHA3 Sponge

SHA3 is built on the "sponge" construction.

A "sponge" function uses a fixed-size internal state, split into a "Rate" and a "Capacity", and it absorbs input data one block at a time. Each block is XORed into the Rate before the whole state is permuted by the Keccak-f[1600] function.

SHA3-256 can serve the same fixed-output cryptographic-hash role as SHA-256, but whose internal design is fundamentally different from the Merkle–Damgård construction used by the SHA2 family of algorithms. As a result, SHA3-256 is often described as a "drop-in" replacement for the SHA2-256 algorithm.

This diagram computes SHA3-256 of one short message, in a single call to Keccak-f[1600]. The state is 25 lanes of 64 bits: a Rate of 17 lanes (1088 bits) and a Capacity of 8 lanes (512 bits), so the digest is 4 lanes (256 bits). "Input block" is the message after SHA3's padding — the message bytes, then 06, then zeros, ending in 80 — and "Output Hash" is the first 32 bytes of the Rate afterwards, shown byte for byte, so it reads exactly as sha3sum prints it. Only a message shorter than one block, and the fixed-length SHA3-256 output rather than the XOF modes, are covered.

The diagram draws "Capacity" on the left and "Rate" on the right so that each sits over the component it feeds. That is for data-flow layout only: in the Keccak state itself, the Rate occupies the first 17 lanes and the Capacity the last 8, as the "A Bytes" arrays inside the Keccak scene show.

"Keccak f(1600)" is a genuine container node: once the walk reaches it, click it to drill into all 24 real rounds of the permutation. Each round shows five named sub-functions — Theta, Rho, Pi, Chi, Iota — each a nested Scene in its own right, and the real round constant Iota consumes, highlighted in "Round Constants". Theta drills in one level further, into the same scenes Nested Scenes draws standalone.

Every value is computed in plain Rust from the one before it, so a nested scene always shows the state entering it, and stepping over a function gives the same result as stepping into it. Round 17's input is round 16's output, Theta's input is that same state, Rho's is Theta's output, and so on. The last round's output is the Rate and Capacity at the bottom of this diagram.
