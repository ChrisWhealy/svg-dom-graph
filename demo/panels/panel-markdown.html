Markdown node

A Markdown node explains something in prose, next to the thing it explains. It draws headings, paragraphs, bulleted and numbered lists, and bold, italic and code runs. Its width is chosen by the caller, and its height is whatever the text needs. Text that is too long for a line wraps between words.

This crate has no Markdown dependency. The node's text is drawn as SVG that the crate lays out itself, in a monospace font, so a general parser that produces HTML would give it nothing it could use. See the docs for the subset it understands.

The node can be dragged, like any other node.
