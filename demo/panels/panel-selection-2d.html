Cell selection: two-dimensional array

A data node can highlight one of its own cells, or — for a two-dimensional grid — a whole row or column plus a further cell within it, via Scene::set_selection. This is how a caller marks "where we currently are" while stepping through an array's values, e.g. one element at a time.

For a two-dimensional array, the walk highlights the whole row currently being processed in one colour. It also highlights the specific cell within that row, in a second, stronger colour. Each example is stepped by its own in-canvas selection toolbar.

The first array has ten values over four columns, so its last row is short by two cells. The second array has three u32 values, shown in hexadecimal, with its rows labelled alphabetically by LabellingStyle::Alphabetic.
