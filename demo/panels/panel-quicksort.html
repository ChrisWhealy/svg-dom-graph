Quicksort

Quicksort sorts by splitting. It picks one element, the pivot, and moves every element smaller than the pivot in front of it and every other element behind it. The pivot is then exactly where it belongs in the sorted array. What is left is two smaller arrays, one on each side of the pivot, and each is sorted the same way. An array of one element is already sorted.

This demo uses the Lomuto partition, in which the pivot is the last element of the range being sorted. One pass looks at each of the other elements in turn. An element smaller than the pivot is swapped with the first element that is not, which grows the group of smaller elements at the front of the range by one. At the end of the pass the pivot is swapped in behind that group.
