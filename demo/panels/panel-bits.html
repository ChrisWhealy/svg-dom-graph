Bit arrays

Not every value is a whole number of bytes. A bit array holds values that are each from one to seven bits wide, all of the same width. Base64 is an example: it cuts three bytes into four six-bit values.

This demo shows every bit width from 1 to 7, both as a single value and also as an array of values. These are formatted in decimal, hexadecimal and binary.

A bit array is made with BitValues::new(width, values), which refuses a width of 0 or more than 7, and a value that does not fit in its width. So a six-bit array can never hold 64.

Binary writes exactly as many digits as the width, with no gap. The gap in the binary form of a whole byte splits it into two nybbles of four bits, which means nothing for a width that is not a multiple of four. Hexadecimal writes one digit for each four bits, or part of four, so a six-bit value is two digits.

The last line shows the difference. The number 19 as a u8 is 0001 0011, with two leading zero bits. As a six-bit value it is 010011. The width is used to construct both the node's tooltip and its accessible type name, such as 6-bit.
