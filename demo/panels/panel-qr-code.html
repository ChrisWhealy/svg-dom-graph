QR Code Generator

A QR code is a square grid of dark and light modules that can be read by an optical scanner or the camera in a phone.

This demo show how the smallest kind is constructed: Version 1, which is 21 by 21 modules, with error correction level L, for text of up to 17 ASCII characters. Every number is worked out in plain Rust by an encoder written for this demo, and checked against two independent encoders. The library draws the nodes and edges, and it encodes nothing.

The diagram follows the text through the stages needed to create the symbol:

  1. Bytes. Each character is one byte.
  2. Bitstream. The mode, the count and the bytes become bits, ended by a terminator.
  3. Data codewords. The bits are cut into 19 codewords of 8 bits, with padding.
  4. Reed-Solomon. Each data codeword takes the remainder of a division one step further. The remainder is the 7 error correction codewords, which let a scanner repair a damaged symbol.
  5. Function modules. The finder, separator and timing patterns and the dark module are drawn first. The format modules are reserved, but have no colour yet.
  6. Placement. The 26 codewords fill the other modules, two columns at a time.
  7. Masks. Each of eight masks flips a pattern of the data modules. Each candidate gets its own format information and is scored, and the lowest score wins.

At the last step, "Export SVG" asks the browser to save the finished symbol as qr-code.svg. The file adds the quiet zone of four light modules that a scanner needs, which the matrix on screen leaves out. It is pure black on white, with every module a whole number of pixels, and it has been read back by an independent decoder.

The scene is large, so it opens in a window of its own.
