Arithmetic operators

An operator node names the operation that produced its own single value — one of the five plain arithmetic operators ADD/SUB/MUL/DIV/MOD — without this crate ever computing that value itself. Each result shown here is computed by the demo, in plain Rust, exactly the way a real caller would; see DataNodeContent.

A binary operator node has two incoming edges, drawn automatically when the node is created, so the rendered graph can never drift from the operand relationship the node claims to represent. Unlike a Boolean operator, an arithmetic one is not commutative: the first operand feeding the node is always the left-hand side, the second always the right-hand side.

Each row uses a different operand width, so between them all four this crate supports — u8/u16/u32/u64 — appear at least once.

See the Chained operators panel for an operator node's own result feeding a further operator node, rather than every row here standing alone.
