Arithmetic operators

An operator node names the operation that produced its own single value — one of the five plain arithmetic operators ADD/SUB/MUL/DIV/MOD — without this crate ever computing that value itself. Each result shown here is computed by the demo, in plain Rust, exactly the way a real caller would; see DataNodeContent.

A binary operator node has two incoming edges, drawn automatically when the node is created, so the rendered graph can never drift from the operand relationship the node claims to represent.

Unlike a Boolean operator, an arithmetic one is only commutative for `add` and `multiply`: the first operand feeding the node is always the left-hand side and the second is always the right-hand side.

The first column holds unsigned integers (u8, u16, u32, u64), the second signed integers (i8, i16, i32, i64), and the third floating point values (f32, f64). Each row uses a different width, so every width this crate supports appears at least once.

The signed column shows what a sign changes. Subtraction can pass below zero, a division truncates towards zero, and a remainder takes the sign of the left-hand operand, so -17 MOD 5 is -2. The floating point column shows each result as the float arithmetic really produced it: 0.1 + 0.2 is 0.30000000000000004 as an f64, and 1.1 * 3 is 3.3000002 as an f32, not 3.3.

See the Chained operators panel for an operator node's own result feeding a further operator node, rather than every row here standing alone.
