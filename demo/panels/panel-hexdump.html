Hexdump

A DataFormat::HexDump node shows its u8 values as a hex dump, in the format of hexdump -C: the bytes in hexadecimal, eight to a group, and then as characters, with anything that is not printable shown as .. Each line holds sixteen bytes and is a cell of its own, and the node is drawn on a black background like a terminal's.

Two details of the format are optional, and HexDumpFormat turns each on separately:

  • with_offset shows the offset of each line, as hexdump -C does. It is off by default.
  • with_total_length adds the final line of hexdump -C, which holds the number of bytes in the dump. It is off by default.

The first four nodes show the same bytes with neither, one and then both of these. The last two show how a dump looks for a single byte, and for a run of bytes that is shorter than a line.
