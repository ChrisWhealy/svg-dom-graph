Dijkstra's Shortest Paths

Dijkstra's algorithm finds the shortest route from one vertex of a weighted graph to the others. Each vertex keeps a distance, the length of the shortest route found to it so far, which starts as ∞ for every vertex except the source, where it is 0. A queue holds the vertices the algorithm has reached.

The algorithm takes the nearest vertex from the queue and settles it: no route found later can be shorter. Then it looks at every edge that leaves that vertex. If going along the edge gives its far end a distance that is strictly shorter than the one it has, the distance is replaced and the vertex is remembered as the predecessor, which is where the route came from. The old entry for that vertex stays in the queue, out of date, and is ignored when it comes out. Weights must not be negative.
