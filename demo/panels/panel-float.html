Floating point

A data node can hold f32 and f64 values as well as integers. Every node below shows the same nine values, one per row. The labels on the left of each row describe the value, and each column formats that value a different way.

Decimal places and significant digits

These are different things, and FloatFormat can ask for either. Decimal places are the digits after the point, however big the value is: pi to 2 places is 3.14, and a tiny -0.000123456 is just -0.00. Significant digits count from the first digit that is not zero, wherever the point falls: the same tiny value to 3 significant digits is -0.000123, and a large one such as 1234567.891 is 1230000, its unwritten digits shown as zeros. A value always shows exactly the digits asked for, so 0 to 3 significant digits is 0.00.

Shortest

The default, and what DataFormat::Decimal means for a float. It is the fewest digits that read back as exactly the same value. So 0.1 + 0.2 is 0.30000000000000004, which is what the sum really is.

Scientific notation

A mantissa and a power of ten, such as 1.235e3. Its precision counts the digits of the mantissa, either after its point or in all. It suits values over a wide range, which in plain notation need very long runs of digits.

Special values and signs

NaN, inf and -inf read the same in every format. A negative zero keeps its sign, -0.0, because the sign is part of a float's value. A sign is never shown for a positive value.

Types and bits

An f32 has fewer digits than an f64, so the same values read differently: its nearest pi is 3.1415927. The hexadecimal and binary formats show the IEEE-754 bits of either, with the sign in the top bit.

Every node is exactly as wide as its widest value needs, and which value that is depends on the format. Under 3 significant digits it is the tiny one, whose leading zeros make it the widest. Under 2 decimal places it is the large one. Under scientific notation the numbers are much the same width, so the sign matters. In every format, -inf is wider than a short number, and a negative number is a character wider than a positive one.
