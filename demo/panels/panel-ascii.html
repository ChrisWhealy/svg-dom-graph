ASCII

Bytes that are text can be shown as characters instead of numbers, in two ways.

DataFormat::Ascii

Every byte is one character, in a cell of its own. A printable ASCII byte is shown as itself, a space as ␣, so that a blank cell is never mistaken for a missing one, and any other byte as ·. A value wider than one byte shows its bytes in byte order with no separator, as the u32 and u16 nodes below do.

DataFormat::PlainText

The whole run of bytes is one line of text in a single box with no grid, and the node counts as a single value. The values must be u8 and printable ASCII; a space stays a space.
