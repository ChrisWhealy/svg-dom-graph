Chained operators

An operator node's own DataNodeContent result is a valid operand for a further operator node, just like any other data node's. This panel shows that chaining directly, rather than the Unary operators/Binary operators/ Arithmetic operators panels' one-operator-per-row layout.

Three chains, each one stage deeper than the last:

  • B rotated right by one bit then XOR'ed with A
  • XOR(w0, AND(NOT(w1), w2)) for three plain values
  • SHA256's "Choose" function Ch(x, y, z) = (x AND y) XOR (NOT(x) AND z), whose x feeds two separate operator nodes — one operand, more than one operator. Every result shown is computed by the demo, in plain Rust, exactly the way a real caller would; see DataNodeContent.
