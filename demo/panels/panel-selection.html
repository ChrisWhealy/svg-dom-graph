Cell selection

A data node can highlight one of its own cells, or — for a two-dimensional grid — a whole row or column plus a further cell within it, via Scene::set_selection. This is how a caller marks "where we currently are" while stepping through an array's values, e.g. one element at a time.

For a one-dimensional array, that is simply the currently selected element, in a single highlight colour. For a two-dimensional array, the walk highlights the whole row currently being processed in one colour. It also highlights the specific cell within that row, in a second, stronger colour.

Operator chain over an array (SHA3's ThetaC) Function

On each step, an operator chain is supplied with a fresh set of values from successive rows of an input array, with the final result written to successive elements of an output array.

SHA3's ThetaC function is a real example: for each row n of a 5×5 input array A, C(n) = A(n,0) XOR A(n,1) XOR A(n,2) XOR A(n,3) XOR A(n,4), written to output array O(n).

svg-dom-graph has no way to change an existing node's own displayed value — only its selection (colour/focus). So each step clears and redraws the whole diagram from scratch with the current row's own real values, rather than trying to update any node in place.

A sits at the top of the canvas, above the chain it feeds; O sits directly below the chain's own final XOR node. A connector always lands on a node's own outer edge, never a specific cell inside it, so putting O right after the chain, with nothing else in between, lets a plain edge from that final node reach O directly — reading as "into the output," not "into the input."

Stepping through the elements of an array is driven by enabling a Scene::show_selection_toolbar. This creates a toolbar inside the diagram containing the buttons Prev, Next and Restart.

The walk starts in an initialised, or "not started" state: that is, before row 0 is processed. Consequently, no row of A is highlighted, and the output row O is entirely blank.

Pressing "Next" or "Previous" move n between the clamped value 0 and 4 When n = 4, pressing Next will not wrap the value round to 0; similarly, pressing "Previous" enough times returns the value to 0 and does not wrap around to 4.

In order to initialise the cell selection to its "not started" state, press "Restart".
