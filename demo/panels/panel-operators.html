Boolean operators

An operator node names the operation that produced its own single value — NOT, a shift or rotate, or AND/OR/XOR — without this crate ever computing that value itself. Each result shown here is computed by the demo, in plain Rust, exactly the way a real caller would; see DataNodeContent.

A unary operator node has one incoming edge; a binary operator node has two. Both are drawn automatically when the node is created, so the rendered graph can never drift from the operand relationship the node claims to represent.

The last row is the two-step chain from the original feature request: B rotated right by one bit, then XOR'ed with A. The rotate node's own result feeds the XOR node as its second operand — an operator node is a valid operand for a further operator, just like any other data node.
