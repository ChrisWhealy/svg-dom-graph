Cell selection: one-dimensional array

A data node can highlight one of its own cells, or — for a two-dimensional grid — a whole row or column plus a further cell within it, via Scene::set_selection. This is how a caller marks "where we currently are" while stepping through an array's values, e.g. one element at a time.

For a one-dimensional array, that is simply the currently selected element, in a single highlight colour. The example is stepped by its own in-canvas selection toolbar (Scene::show_selection_toolbar) rather than an external button. The walk starts "not started", before element 0. Next and Previous stop at either end instead of wrapping round, and Restart returns to "not started".
