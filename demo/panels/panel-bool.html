Booleans

A data node can hold bool values. A BoolFormat chooses how true and false are written: as the words, as the bits 1 and 0, or as a green check mark and a red cross. The marks have different shapes, so colour is not the only thing that tells them apart, and a screen reader is told true or false and never the name of a glyph. Every format gives both values a cell of the same width, so a node that changes from one to the other does not outgrow its cells. Under any other format a Boolean is the single byte it is held in.

The first diagram shows true and false singly, and as an array, in each format. The last line is hexadecimal, the byte that a Boolean is held in.

Logical operators

A Boolean can be an operand of NOT, AND, OR, XOR, NAND, NOR and XNOR. It cannot be an operand of a shift, a rotation, a reversal or an arithmetic operator, since there is no sum of two Booleans and no true to rotate. Use a u8 for a one-bit number.
