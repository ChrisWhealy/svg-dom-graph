Unary operators

An operator node names the operation that produced its own single value — NOT, a shift or rotate, or a bit/byte reversal (RBIT/BSWAP) — without this crate ever computing that value itself. Each result shown here is computed by the demo, in plain Rust, exactly the way a real caller would; see DataNodeContent.

A unary operator node has one incoming edge, drawn automatically when the node is created, so the rendered graph can never drift from the operand relationship the node claims to represent.

See the Binary operators panel for AND/OR/ XOR/NAND/NOR/XNOR, and the Chained operators panel for an operator node's own result feeding a further operator node.
