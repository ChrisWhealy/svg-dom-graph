Unary operators

An operator node is based on a data node that has been automatically labelled with the name of the operation it is visualising. For example, a NOT, a bitwise shift or rotate, or a bit/byte reversal (RBIT and BSWAP).

IMPORTANT

An operator node never calculates the the result of the operation! Instead, it simply displays the value supplied by the caller. Therefore, the caller must correctly perform the calculation in plain Rust and supply the result to the operator node; see DataNodeContent.

A unary operator node has one incoming edge, drawn automatically when the node is created, so the rendered graph can never drift from the operand relationship the node claims to represent.

See the Binary operators panel for AND, OR, XOR, NAND, NOR, XNOR, the Arithmetic operators panel for ADD, SUB, MUL, DIV, MOD, and the Chained operators panel for an operator node's own result feeding a further operator node.
