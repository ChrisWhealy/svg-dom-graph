Signed integers

The signed widths — i8, i16, i32 and i64 — are shown here as a single value and as an array of several, in decimal, hexadecimal and binary. Each is given a deeper shade of the colour of its unsigned equivalent.

A sign is shown only when a value is negative, so -5 has one and 42 has none. Hexadecimal and binary show the value's two's-complement representation, so -2 as an i8 reads FE and as an i16 reads FF FE, in the default big-endian byte order.

Each array holds a negative value, zero, a positive value, and the smallest and largest value of its width. The smallest is a one followed by zeros in binary, and has no positive counterpart.
